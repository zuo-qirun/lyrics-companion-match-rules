# 提交与审核

## 应用内提交（推荐）

1. 打开「匹配规则」，写好或导入规则包。
2. 点「提交到市场」，填写作者与说明。
3. 提交成功后会得到提交 id（形如 r-xxxxxxxx）和查询 token，请保存 token 以便查询审核状态。
4. 审核通过后，其他用户在「规则市场」即可看到并一键启用。

## GitHub 提交（备用）

没有安装应用时，使用主仓库 Issue 表单：

https://github.com/zuo-qirun/Lyrics-Companion/issues/new?template=match_rule.yml

表单会要求：规则名称、播放器包名、问题描述、规则 JSON、验证歌曲、是否同意收录。

## 审核标准

- 能在真实元数据上复现，清洗结果更接近词库歌曲；
- 作用域最小，不误伤其他播放器或歌曲；
- 正则安全，动作字段合法，动作用 type；
- 不含隐私数据（本地路径、账号、设备标识）；
- 与已有规则不重复、不冲突。

## 审核结果

- 通过：进入市场目录，所有用户可见；
- 拒绝：记录与备注保留，可修改后重新提交；
- 下架：管理员禁用，目录与下载立即消失；已安装用户可在本地停用。

## 查询与举报

- 用提交时的 id + token 可查询审核状态；
- 市场条目支持举报，管理员会复核并决定是否下架。

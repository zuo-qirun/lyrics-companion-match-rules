# 条件与动作

## when 条件

条件是一个数组，全部满足（AND）才执行 then；最多 6 个。字段取值：title、artist、album、package、source。

| op | 含义 |
| --- | --- |
| equals | 忽略大小写、去首尾空白后全等 |
| equalsAny | value 为字符串数组，任一相等 |
| contains | 包含子串 |
| containsAny | 包含数组中的任一子串 |
| startsWith | 前缀匹配 |
| endsWith | 后缀匹配 |
| regex | 正则 find，忽略大小写，长度 ≤200 |
| empty | 字段为空；此时忽略 value |

注意：**条件用 op**。例如：

~~~json
{"field": "artist", "op": "equalsAny", "value": ["车载音乐", "未知歌手"]}
~~~

## then 动作

动作按顺序执行，单个动作失败只跳过它，不影响整条规则；最多 8 个。动作只能写 title、artist、album。

| type | 参数 | 说明 |
| --- | --- | --- |
| extract | pattern、targets | 用正则抽取编号组到字段；targets 形如 {"artist": 1, "title": 2} |
| replace | field?、pattern、replacement、all? | 正则替换，replacement 支持 $1–$9，all 缺省 true |
| set | field、value | 写入字面量 |
| clear | field | 清空字段 |
| trim | field | 去首尾空白 |
| stripSuffix | field?、pattern? | 去掉标题末尾序号；pattern 缺省匹配 1–3 位数字括号 |
| aliasArtist | map | 艺名→本名映射，按 / 逗号 、 & ; feat. 拆分后逐段替换 |

**动作必须用 type，不能写 op。** 这是服务端与应用端共同校验的硬性要求：

~~~json
{"type": "extract", "pattern": "(.+) - (.+)", "targets": {"artist": 1, "title": 2}}
~~~

## 执行顺序与结果

- 规则包按「内置 → 市场启用 → 个人」顺序执行，包内按 rules 数组顺序。
- 每次字段变化都会记录一个候选快照；最终值作为主候选，其余去重后作为备选。
- 原始 title/artist 永远保留为第一候选，规则不会覆盖播放器原始值。

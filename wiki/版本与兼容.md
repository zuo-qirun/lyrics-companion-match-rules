# 版本与兼容

## 规则包版本

- 同 id 的规则包版本必须递增，服务端会拒绝重复版本；
- 新版本审核通过后替换旧版本，市场只展示最新版；
- 应用缓存按规则包版本失效，启用新版本后重新生成候选。

## 最低应用版本

minVersionCode 用于声明规则依赖的客户端能力：

- 0 表示任意版本可用；
- 使用新动作/新条件时，填写引入该能力的 versionCode；
- 应用版本低于 minVersionCode 时忽略该包，不会报错。

## API 19 兼容

规则引擎运行在 Android 4.4 以上设备：正则只用 Java 7 语法，不使用命名组与反向引用；规则包解析不使用 API 19 以上才有的类。

## 降级

规则包可以随时停用或删除，不改变播放器元数据，也不影响已缓存的歌词；出现误伤时优先停用单条规则而非卸载应用。
